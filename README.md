# 나의 주간 플래너

아이보리 배경과 검정 선으로 구성한 개인용 주간 웹 플래너입니다. Vite와 기본 JavaScript로 만들었으며, 백엔드나 계정 없이 사용할 수 있습니다.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다.

```bash
npm ci
npm run dev
```

터미널에 표시된 주소를 브라우저로 엽니다. 기본 포트는 5173입니다. 클라우드에서는 실행 환경의 포트 전달 기능을 사용하세요.

```bash
npm run build    # dist/에 정적 배포 파일 생성
npm run preview  # 빌드 결과 확인
npm test         # Playwright 실제 브라우저 테스트
npm run build:pages  # GitHub Pages용 docs/ 갱신
```

테스트는 `CHROMIUM_PATH`, `/usr/bin/chromium`, `/usr/bin/google-chrome` 순으로 브라우저를 찾습니다. 없는 환경에서는 먼저 `npx playwright install chromium`을 실행하세요. npm 캐시 쓰기 권한이 제한된 환경에서는 `npm ci --cache /tmp/planner-npm-cache`로 설치할 수 있습니다.

## 사용법

- 왼쪽 제목에 이름을 입력합니다.
- **한 달 해야 할 일**: `+ 한 달 할 일 추가`로 할 일과 시작일·마감일을 정합니다. 달별로 넘겨볼 수 있고, 각 항목에 남은 기간(D-n, 기한 지남 등)과 그 달 안에서의 기간 막대가 표시됩니다. 이번 주에 걸친 할 일은 오른쪽 시간표 위에도 막대로 나타나며, 누르면 수정할 수 있습니다.
- **일주일 해야 할 일**: `+ 항목 추가`로 ‘과제’, ‘프로젝트’ 같은 항목을 색과 함께 만들고, 항목 옆 `+`로 그 안에 세부 할 일을 추가합니다(Enter로 연속 입력, Esc로 닫기). 항목은 매주 유지되고 할 일은 주별로 저장됩니다. 항목 이름을 누르면 이름·색·노션 링크를 바꾸거나 삭제할 수 있습니다.
- **노션 연결**: 상단 `노션 연결`에 노션 페이지 주소를 저장하면 `노션 열기`로 바로 이동합니다. 항목과 한 달 할 일마다 노션 페이지를 따로 연결할 수도 있습니다(링크로 여는 방식이며 노션 데이터와 동기화되지는 않습니다).
- 시간표 아래의 보완할 점은 여러 줄로 작성할 수 있습니다.
- 오른쪽 월~일 시간표의 빈 칸을 누르면 해당 날짜와 시간으로 일정 입력창이 열립니다.
- 07:00부터 24:00까지 30분 단위로 일정을 등록합니다. 일정 제목을 누르면 수정·삭제할 수 있으며 체크박스로 완료 상태를 바꿉니다.
- 겹치는 일정은 나란히 표시됩니다. 오전 7시부터 자정까지 시간표 전체가 펼쳐집니다. 짧은 일정은 제목을 한 줄로 표시하며, 누르면 전체 내용과 시간을 확인할 수 있습니다.
- 이전 주·다음 주·이번 주 버튼으로 이동합니다. 주간 할 일, 메모, 일정과 완료 상태는 주별로 보관되고 이름·항목·한 달 할 일·노션 링크는 공통으로 사용됩니다. 이전 버전에서 적은 할 일은 기본 항목 ‘할 일’로 자동으로 옮겨집니다.
- 좁은 화면에서는 왼쪽 영역과 시간표가 위아래로 배치되며 시간표는 가로 스크롤할 수 있습니다.

## 저장

입력할 때마다 현재 브라우저의 `localStorage`에 자동 저장합니다. 날짜는 사용 기기의 현지 날짜를 기준으로 하며 한 주는 월요일부터 시작합니다. 같은 브라우저와 같은 사이트 주소(포트 포함)에서 다시 열면 복원됩니다. 다른 기기와 동기화되지 않으며, 브라우저 사이트 데이터를 지우면 내용도 삭제됩니다. 저장이 차단되거나 공간이 부족하면 상단에 안내가 표시됩니다.

## 검증

`tests/planner.spec.js`는 항목별 할 일, 한 달 할 일 기간 검증, 노션 링크, 이전 데이터 이전과 일정 추가·수정·삭제, 시간 유효성 검사, 완료와 취소, 할 일 편집·삭제, 메모, 주 이동, 새로고침 후 복원, 자정 종료, 일정 겹침, 모바일 페이지 너비를 검증합니다.
