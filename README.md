# 나의 주간 플래너

아이보리 배경과 검정 선으로 구성한 개인용 주간 웹 플래너입니다. Vite와 기본 JavaScript로 만들었으며, 백엔드나 계정 없이 사용할 수 있습니다.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다.

```bash
npm ci
npm run dev
```

터미널에 표시된 주소를 브라우저로 엽니다. 기본 포트는 5173입니다. 클라우드에서는 실행 환경의 포트 전달 기능을 사용하세요.

```bash
npm run build    # dist/에 정적 배포 파일 생성
npm run preview  # 빌드 결과 확인
npm test         # Playwright 실제 브라우저 테스트
```

테스트는 `/usr/bin/chromium`이 있으면 사용합니다. 없는 환경에서는 먼저 `npx playwright install chromium`을 실행하세요. npm 캐시 쓰기 권한이 제한된 환경에서는 `npm ci --cache /tmp/planner-npm-cache`로 설치할 수 있습니다.

## 사용법

- 왼쪽 제목의 이름을 입력하고, 할 일을 추가합니다. 항목의 글을 바로 수정하거나 완료 체크·삭제할 수 있습니다.
- 보완할 점은 여러 줄로 작성할 수 있습니다.
- 오른쪽 월~일 시간표의 빈 칸을 누르면 해당 날짜와 시간으로 일정 입력창이 열립니다.
- 07:00부터 24:00까지 30분 단위로 일정을 등록합니다. 일정 제목을 누르면 수정·삭제할 수 있으며 체크박스로 완료 상태를 바꿉니다.
- 겹치는 일정은 나란히 표시됩니다. 시간표 내부를 스크롤하면 늦은 시간까지 볼 수 있습니다.
- 이전 주·다음 주·이번 주 버튼으로 이동합니다. 할 일, 메모, 일정과 완료 상태는 주별로 보관되고 이름은 공통으로 사용됩니다.
- 좁은 화면에서는 왼쪽 영역과 시간표가 위아래로 배치되며 시간표는 가로 스크롤할 수 있습니다.

## 저장

입력할 때마다 현재 브라우저의 `localStorage`에 자동 저장합니다. 날짜는 사용 기기의 현지 날짜를 기준으로 하며 한 주는 월요일부터 시작합니다. 같은 브라우저와 같은 사이트 주소(포트 포함)에서 다시 열면 복원됩니다. 다른 기기와 동기화되지 않으며, 브라우저 사이트 데이터를 지우면 내용도 삭제됩니다. 저장이 차단되거나 공간이 부족하면 상단에 안내가 표시됩니다.

## 검증

`tests/planner.spec.js`는 일정 추가·수정·삭제, 시간 유효성 검사, 완료와 취소, 할 일 편집·삭제, 메모, 주 이동, 새로고침 후 복원, 자정 종료, 일정 겹침, 모바일 페이지 너비를 검증합니다.
